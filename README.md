# 📊 Online Retail — Data Cleaning & Preparation

**Cleaning raw retail data and preparing it for meaningful analysis using Microsoft Excel.**

## 📝 Project Summary

This project focuses on improving the quality of the Online Retail II dataset by identifying duplicate records, checking missing values, investigating unusual transactions, and preparing new columns for analysis.

The workbook contains two worksheets covering **2009–2010** and **2010–2011**.

## 🎯 Project Objectives

- Improve data quality and consistency.
- Identify duplicate records and missing values.
- Investigate unusual quantity and price values.
- Validate invoice dates.
- Calculate transaction sales amounts.
- Standardize product descriptions.

## 🛠️ Tools & Skills

`Microsoft Excel` `Data Cleaning` `Data Validation` `Excel Formulas` `Data Quality Analysis`

**Formulas used:** `TRIM()` · `ISNUMBER()` · `SUM()`

## 🧹 Cleaning Process

| Step | Task |
|---|---|
| 1 | Identified and removed exact duplicate rows |
| 2 | Checked missing descriptions and customer IDs |
| 3 | Investigated negative and zero quantities and prices |
| 4 | Validated invoice dates |
| 5 | Created `Sales_Amount` using Quantity × Price |
| 6 | Created `Clean_Description` using `TRIM()` |
| 7 | Prepared a data quality summary |

## 📈 Key Takeaways

- Identified missing values in important fields.
- Flagged unusual transactions for further investigation.
- Created calculated sales amounts for analysis.
- Improved product description consistency.
- Prepared the workbook for future sales analysis.
