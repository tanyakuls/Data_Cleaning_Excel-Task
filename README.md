# Online Retail — Data Cleaning & Preparation

## Project Overview
This project uses Microsoft Excel to clean and prepare the Online Retail II dataset for further analysis.

## Tools Used
- Microsoft Excel
- Filters and Remove Duplicates
- Formulas: `TRIM()`, `ISNUMBER()`, `SUM()`

## Tasks Performed
- Identified and removed exact duplicate rows.
- Checked missing values.
- Investigated unusual quantities and prices.
- Validated invoice dates.
- Created a `Sales_Amount` column.
- Cleaned descriptions using `TRIM()`.
- Prepared a data quality summary.

## Project File
- `cleaned_Data Sampled.xlsx` — Sample cleaned dataset.

## Outcome
Practiced data cleaning, validation, and preparation using Excel.
